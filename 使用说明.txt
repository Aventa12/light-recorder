轻录 0.3 · Windows 轻量录屏

安装版：运行“轻录-Win10-x64-安装包.exe”，按向导安装。默认安装到当前用户的程序目录，创建开始菜单入口，可选创建桌面快捷方式。安装结束可直接启动。
便携版：解压完整文件夹后双击“轻录.exe”。不要单独移动 exe，旁边的 ScreenRecorderLib.dll 和 轻录.exe.config 必须保留。
支持：64 位 Windows 10 2004 或更新版本 / Windows 11，需要 .NET Framework 4.8、x64 Visual C++ 2015–2022 运行库和系统媒体组件。Windows N/KN 需安装 Media Feature Pack。
安装版自带微软官方 x64 C++ 运行库，缺少或版本过旧时自动安装，此时可能请求管理员许可或提示重启。正常 Windows 10 2004 及更新版本已经包含 .NET Framework 4.8，安装程序会检查。
N/KN 版本缺少媒体组件时，安装程序尝试通过 Windows Update 安装，需联网和管理员许可。系统组件损坏、系统策略禁止安装或拒绝依赖安装时，会明确提示，不会跳过检查冒充安装就绪。
便携版若缺少 C++ 运行库，可从微软下载：https://aka.ms/vc14/vc_redist.x64.exe

1. 选择全屏、窗口或区域。多屏时可选择显示器；区域在所选显示器内拖动框选，Esc 取消。窗口模式显示已选窗口名称和绿色边框；“定位窗口”可切到目标，重新打开下拉列表会刷新可选窗口。
2. 分别开启电脑声音、麦克风，或全部关闭。声音使用 Windows 默认设备；窗口录制开启“电脑声音”时会录入整个系统声音。
3. 默认限制到 1080p 高度、保持比例、不放大小画面；可选 720p 或原始分辨率。默认 30 帧，60 帧适合较多动态内容，但实际帧率受硬件性能影响。
4. 点击开始，目标屏幕右下角显示倒计时（可取消）。开始后原位置显示录制时长和“暂停/继续”“停止”按钮。默认主窗口最小化到系统托盘，可双击托盘图标恢复。
5. Ctrl + Alt + F9：开始 / 暂停 / 继续。Ctrl + Alt + F10：结束并保存。快捷键冲突时可使用托盘菜单操作。
6. 安装版默认保存在用户“视频”文件夹下的“轻录”目录；便携版默认保存在程序旁的“录制视频”文件夹。都可更改位置。输出为 H.264/AAC MP4，无水印。

“鼠标点击高亮”表示点击时显示彩色圆点，不是持续跟随光标的光圈。
暂停的时间不会计入视频。退出时若仍在录制，将询问是否保存后退出。
输出使用分段 MP4，异常中断时已经写入的片段有机会恢复；不保证断电后所有内容完整。
窗口录制请保持目标窗口展开，不要最小化。受保护内容、权限隔离窗口可能显示黑屏。
右下角悬浮控制条和绿色选择边框启用 Windows 录制排除，不会出现在本软件录制的画面中。若 Windows 无法启用控制条排除，软件会提示并阻止开始，避免误录。倒计时在实际录制开始前显示。
音频设备在录制途中切换时建议结束录制后重新开始；首次使用麦克风请允许桌面应用访问麦克风。
若启动或编码失败，可关闭“优先使用硬件编码”重试。声音同时开启时建议佩戴耳机以减少回声。

无账号、无云端上传、无后台更新。安装版设置保存在 %LOCALAPPDATA%\LightRecorder\settings.json；便携版设置保存在同目录 settings.json，便携文件夹需具有写入权限。卸载安装版会保留用户设置和视频。
视频容量与画面复杂度和时长有关，与软件本身体积分开计算。
