# 验证记录

验证环境：Windows 10 Enterprise LTSC 2021，21H2，19044，x64。

## 录制和控制

- 全屏无声、窗口、区域暂停、系统声音、麦克风、双声混录、硬件编码 1080p/60 帧设置共七项录制验证通过。
- Windows 自带解码器能打开全部输出并提取画面。常规测试视频为 4 秒；区域录制中暂停约 1 秒，成片为 3 秒。
- 已选窗口标题与绿色边框、右下角倒计时及取消、悬浮按钮暂停/继续/停止的实际交互验证通过。
- 成片中普通红色测试标记正常保留；控制条所处位置显示后方测试背景，确认控制条未写入视频。其四处检查点的像素颜色与背景相差不超过 5。

## 图标和安装

- 用户原图与工程内原图的 SHA-256 一致；16/24/32/48/64/128/256 像素图标均已嵌入程序与安装器。
- 安装包内微软 x64 C++ 运行库的数字签名有效。
- 最终安装返回码为 0，桌面和开始菜单快捷方式创建正确。
- 安装后检查成功加载实际录制核心及 C++ 依赖、初始化 Media Foundation、读取图标并确认用户目录就绪。
- 安装后的程序完成了实际录制及控制条交互测试。
- 卸载返回码为 0，清理应用、快捷方式及测试安装登记，并保留用户视频目录内的验证文件。验证文件随后单独移除。
- 发布便携包通过 ZIP 完整性检查，不含安装模式标记、个人设置或录制视频。

## 验证范围

测试机已有可用的 C++ 运行库，因此未实测缺失运行库首次安装和 Windows N/KN 媒体功能包下载分支，也没有进行全新虚拟机矩阵测试。安装器会检查依赖并在失败时报告错误。

录制验证确认音频轨道与录制通路，不代表已测量实际音量、混音质量、长时间同步或全部设备兼容性。60 帧是目标设置，实际帧率受画面与硬件影响。分段 MP4 只能尽量保留异常退出前已写入的片段，不能保证断电后完整恢复。

历史截图、短时录制文件及安装日志已清理；回归测试源码保留在 `tests/`，可以按需重新执行。
